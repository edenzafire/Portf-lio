Este é o meu **primeiro projeto web**, desenvolvido em 2022 como parte do meu aprendizado em desenvolvimento front-end.  
O objetivo foi criar uma **landing page simples, responsiva e funcional**, usando apenas tecnologias básicas da web.

---

## 🚀 Tecnologias Utilizadas

- 🧱 HTML5  
- 🎨 CSS3  
- ⚡ JavaScript  

---

## 🎯 Objetivo do Projeto

- Praticar os fundamentos do Front-End  
- Criar uma landing page funcional do zero  
- Entender melhor estrutura, estilos e lógica em JS
